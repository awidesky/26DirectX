중간고사 문제

(10점)
1. 백버퍼의 크기를 800 * 800으로 수정하고 윈도우의 크기를 맞추시오.

2. C키 누르면 600 * 600윈도우로 변경되도록 input()에 추가하시오.

3. GameObject의 Update 로직을 짜시오. (start()는 1번만 불리도록 하는 로직 필수)

4. WinMain의 쉐이더 코드 부분을 작성하시오 (ConstantBuffer는 MeshRenderer에서 업데이트한다)

5. WinMain에 삼각형을 지우고 별을 만들어보자 (5망성) (별객체를 새로 생성하며 이름을 gstar로 한다.)
   (삼각형 3개를 이용하여 그리는거 검색해보면 나옴. 꼭지점을 이었을때 정오각형 이어야함)

(20점)
6. 별을 n개 만들어서 사이즈와 위치, 색상을 랜덤하게 배치하는 코드를 WinMain에 만들자. 
   (최대 크기는 화면 가로길이인 800 의 1/4 크기로)

7. 컨트롤러를 새로 만들어 사이즈에 따라서 이동속도/회전속도/사이즈조정 속도가 다르도록 하자.
   (이름은 StarController. 크기가 작을수록 느리게, 클수록 빠르게)

(10점)
